# ポートフォリオの更新

`portfolio.json` がテーマページと作品一覧の共通データです。
`python3 scripts/build-portfolio.py` で静的HTMLを再生成します。

## 年ごとの共通フォーマット

- year: 制作年
- title: その年のテーマ
- intro: テーマについて（場所、関心、制作のつながり）
- focus: 関心・素材
- cover: 写真または映像のポスター
- video: 既存の映像パス。映像がない年は空文字とし、写真を表示
- caption: 写真・映像の作品名と場所。作品映像を年全体の総集編と称さない
- work: メインの作品ID

## 作品の共通フォーマット

id / title / year / summary / cover / methods / url を全作品で揃えます。
作品詳細にも制作年・年のテーマ・素材技法を自動で表示します。
詳細の本文は既存の執筆内容を保持します。新作は以下を基準に記述してください。

1. 作品名と概要（何を作ったか）
2. 制作年、制作場所、素材・技法、寸法・期間、担当・協働者（確認できた情報のみ）
3. 全景とキャプション
4. 出発点、制作上の判断、仕組みや工程
5. 細部・体験・制作過程の写真と説明
6. 展示・公開記録、関連資料へのリンク

年のテーマと制作場所は別の情報です。2026年のテーマは京都、織部鉄絵四方皿の制作場所は多治見・住吉窯。
未確認の寸法や担当者などは推測で補いません。

## 制作の庭（Themes）と記録（Works）

- `index.html` と互換URLの `projects.html` は「制作の庭」。
- `assets/garden/garden.svg` は庭の原画。ビルド時にページ内へ埋め込まれます。
- `assets/garden/garden.css` が庭のレイアウト・動きを担当します。
- 原画の各場所と、HTML上のテーマ名から `#year-YYYY` の全体図に画面が切り替わります。
- JavaScriptなしでもアンカーとCSSの `:target` で図が切り替わります。動きを抑える端末設定にも対応します。
- `works.html` は年ごとのテーマ説明、作品映像、全作品の一覧です。
- 新しい年を追加するときはデータに加え、庭の場所と `.label-YYYY` の位置も編集します。

## テーマの内側の全体図

- `world-2023.svg` ～ `world-2026.svg` が各テーマの詳細イラストです。
- 全体の庭 → テーマの図 → 庭へ戻る、の画面切替です。スクロールによる遷移や動画表示は使いません。
- ブラウザーの戻る・進む、Esc、直接リンク、キーボード操作に対応します。
- テーマの本文はビルドスクリプトの `world_notes` に、同じ三項目の形式で記述しています。
- 図中のモティーフはテーマの全体像を示します。制作済みの作品と学習中の領域を区別して表記します。
- 図の中から個別作品へは遷移しません。各テーマ上部の「作品一覧」からWorksへ進めます。
